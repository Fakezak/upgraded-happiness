# ZakXeno Modz Proxy

This is a visual modding simulation interface for Free Fire built for entertainment and UI concept only.

## Features:
- Fake visual unlocks for skins, diamonds, passes
- Mod menu with toggles
- Hacker-style design

## Setup Instructions:
1. **Use VS Code or CodeSpace** and open the folder.
2. Place all files (`index.html`, `modmenu.html`, `loader.html`, `style.css`, `modmenu.js`) inside.
3. Create an `assets` folder with optional hacker-style background image.
4. Run via `Live Server` extension or host on GitHub Pages for free.

## Note:
- This is not a real hack. It simulates a Free Fire private server for fun.
- Intended for UI/UX concept use only.
